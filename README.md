# OpenSees TCL Runner - برنامه اجرای فایل‌های TCL

یک برنامه حرفه‌ای و زیبا برای اجرای فایل‌های TCL در OpenSees

## ویژگی‌ها

✨ **رابط کاربری زیبا و مدرن**
- طراحی شیک و حرفه‌ای
- پشتیبانی کامل فارسی
- تم‌های مختلف (روشن و تاریک)

🚀 **کارکردی و قدرتمند**
- انتخاب فایل از هر درایو
- اجرای فایل‌های TCL مستقیم
- نمایش خروجی و خطاها
- ذخیره‌سازی فایل‌های اخیر

📁 **مدیریت فایل‌ها**
- مرور سریع پوشه‌های مختلف
- لیست فایل‌های اخیر
- جستجو و فیلتر

## نیازمندی‌ها

- Python 3.8+
- OpenSees نصب‌شده در `C:\ActiveTcl\bin`
- کتابخانه‌های Python (مندرج در `requirements.txt`)

## نصب و اجرا

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای برنامه
python main.py
```

## ساختار پروژه

```
├── main.py                 # فایل اصلی برنامه
├── ui/
│   ├── main_window.py     # پنجره اصلی
│   ├── styles.py          # استایل‌های CSS
│   └── icons/             # آیکون‌ها
├── core/
│   ├── runner.py          # موتور اجرای TCL
│   └── config.py          # تنظیمات
├── requirements.txt       # وابستگی‌ها
└── README.md
```
