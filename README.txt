نرم‌افزار آیین‌نامه ۲۸۰۰ — ویرایش پنجم  |  نسخهٔ دسکتاپ ویندوز
طراح و سازنده: سجاد فروزنده
================================================================

ساخت فایل exe (یک‌بار، روی ویندوز):
1) پایتون ۳٫۱۰ یا بالاتر را نصب کنید (گزینهٔ Add Python to PATH را بزنید).
2) روی build.bat دوبار کلیک کنید. چند دقیقه صبر کنید.
3) فایل dist\Seismic2800.exe ساخته می‌شود؛ مستقل است و به نصب پایتون نیاز ندارد.

نصب‌کنندهٔ حرفه‌ای (اختیاری):
Inno Setup را نصب کنید، installer.iss را باز و Compile کنید تا Seismic2800_Setup.exe ساخته شود.

فونت بدون اینترنت (اختیاری):
فایل Vazirmatn.woff2 (فونت متن‌باز وزیرمتن) را در app\fonts بگذارید و دوباره build.bat را اجرا کنید.
بدون آن، فونت از اینترنت بارگذاری می‌شود و بدون اینترنت فونت پیش‌فرض ویندوز جایگزین می‌شود.

نکته‌ها:
- پروژه‌ها و سناریوها خودکار در پوشهٔ %APPDATA%\Seismic2800 ذخیره می‌شوند.
- «دریافت گزارش PDF» پنجرهٔ چاپ ویندوز را باز می‌کند؛ چاپگر Microsoft Print to PDF را انتخاب کنید.
- خروجی XLSX برای ساخت فایل به اینترنت نیاز دارد (کتابخانهٔ SheetJS از cdnjs)؛ CSV همیشه کار می‌کند.
- ویندوز ۱۰/۱۱ با WebView2 لازم است (معمولاً از قبل نصب است).
- برای تست بدون ساخت exe:  pip install pywebview  و سپس  python app.py


================ بدون نصب پایتون ================
روش ۱ — فوری (بدون exe): فایل Launch_Seismic2800.vbs را دوبار کلیک کنید.
  برنامه در پنجرهٔ مستقل Edge (بدون نوار آدرس) باز می‌شود. می‌توانید میان‌بر آن را روی دسکتاپ بگذارید.
  ذخیرهٔ CSV/XLSX با دانلود معمولی مرورگر انجام می‌شود. پوشهٔ برنامه را جابه‌جا نکنید.

روش ۲ — ساخت exe در فضای ابری GitHub (بدون نصب هیچ چیزی روی رایانهٔ شما):
  1) در github.com یک مخزن (Repository) خصوصی بسازید.
  2) همهٔ فایل‌های این پوشه (از جمله پوشهٔ .github) را با Add file > Upload files آپلود کنید.
  3) به تب Actions بروید > Build Windows EXE > Run workflow.
  4) پس از چند دقیقه، در پایین صفحهٔ اجرا، Artifact با نام Seismic2800-Windows را دانلود کنید؛ داخلش هم Seismic2800.exe (قابل‌حمل) و هم Seismic2800_Setup.exe (نصب‌کننده) است.
  فایل exe نهایی روی هر ویندوزی بدون پایتون اجرا می‌شود.
